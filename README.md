This Python script uses Selenium to scrape Accounting and Finance job listings from Wuzzuf.

It automatically:
- Opens Wuzzuf and navigates through job listing pages.
- Extracts Job Name, Company Name, Location, Job Type, Workplace, and Application Link.
- Stores the collected data in a Pandas DataFrame.
- Stops when no more job listings are found.
- Prints the first few rows of the collected data.

Technologies: Python, Selenium, Pandas
